Important

        

          
Files
Read in the browser only. Nothing is uploaded anywhere.

          
Requires
three.js and the icon font come from a CDN, so the first run needs a connection; the browser cache covers it after that. Tested on Chrome.

          
Settings
Display, Grid, Navigation, Camera, Ghost and Color preferences are kept in this browser. Whatever the file decides — fps, take, visibility, the playback range — starts fresh every time. Only what you have moved off its default is stored, so a reset simply drops it; the buttons beside a value, and Reset All Settings at the foot of the pane, are live only when there is something to undo.

          
Textures
Textures embedded in the file are shown, ASCII and binary alike. Ones left as separate files are not read, so embed them when you export.

        


        
Navigation

        

          
Tumble
Left drag (Alt optional)

          
Track
Middle drag (Alt optional)

          
Dolly
Alt + right drag, or the mouse wheel

          
Frame
Fits the visible meshes at the current angle. Unavailable while an FBX camera is selected, since that would overwrite its authored transform.

        
Rotation Lock
On a touch device, the axis-aligned views lock rotation so a two-finger pan cannot tip the view; one finger pans instead. Turn it off to orbit from there.

        


        
Keyboard

        

          
Space
Play / pause

          
Left / Right
Step one frame

          
Esc
Close this window

        


        
Worth knowing

        

          
Viewpoint
Cameras in the file are listed after the standard views. Focal length animation and aim constraints are reproduced.

          
fps
The conversion between seconds and frames, detected from the file. It sets frame numbering, stepping, Snap and the Range boundaries — not the playback rate.

          
Range
Plays a sub-section. Start and End are kept when Range is switched off.

          
Snap
Samples whole frames instead of real time, the way a DCC timeline steps.

          
Skeleton Ghost
Draws the skeleton at surrounding frames. Span, Step and direction are in the Ghost group.

          
Gate Mask
Resolution gate for FBX cameras. Gate Fit follows the file, so the framing matches the DCC it came from.

          
Units
One grid cell is a metre, converted through the unit scale the file records — a scene authored in centimetres still gets metre cells. Grid Size adds ten cells to each side per level, so level 1 is a ten metre square.

          
Grid Fill
A solid plane over the grid. It is one-sided, so it hides what is below the ground when seen from above but not from underneath.

          
Frame Cameras
Widens Frame to take in the cameras and their aim targets.

          
Visibility
Each mesh cycles between Show, Hide and Anim. Anim follows the visibility keys in the file; a hidden group hides its meshes. Visibility is on or off at each key — 3ds Max's linear fade to partial transparency is not reproduced.

          
Hidden in 3ds Max
Max keeps an object's hidden state apart from its Visibility track and writes it separately; both are read here. The hidden state covers that object alone, so hiding a bone or a dummy leaves whatever hangs off it on screen, as it does in Max. Where a mesh has both, the Visibility track wins — so key Visibility for anything that has to change during the shot.

        

      


          

        
重要

        

          
Files
FBXはブラウザ内で読み込まれるだけで、どこにもアップロードされません。

          
Requires
three.jsとアイコンフォントをCDNから読み込むため、初回のみネット接続が必要です（以降はブラウザキャッシュ）。動作確認はChromeです。

          
Settings
Display/Grid/Navigation/Camera/Ghost/Colorの設定はこのブラウザに保存されます。fps・テイク・可視性・再生区間などファイルが決めるものは毎回初期状態から始まります。既定値から動かした項目だけが保存されるので、リセットはその削除にあたります。値の横のリセットボタンと、ペイン下部のReset All Settingsは、戻すものがあるときだけ有効になります。

          
Textures
ファイルに埋め込まれたテクスチャは表示されます（アスキー・バイナリとも）。外部ファイルを参照しているものは読み込まないので、書き出し時に埋め込んでください。

        


        
視点操作

        

          
Tumble
左ドラッグ（Altは任意）

          
Track
中ドラッグ（Altは任意）

          
Dolly
Alt+右ドラッグ、またはマウスホイール

          
Frame
現在の角度のまま、表示中のメッシュが収まる位置へ寄ります。FBXカメラを選択中は使えません（カメラに設定された変換を上書きしてしまうため）。

        
Rotation Lock
タッチ入力の端末で軸に沿った視点に切り替えると回転をロックします。2本指の移動中に視点が傾くのを防ぐためで、1本指は移動に割り当てられます。回したい場合はオフにしてください。

覚えておきたいこと

        

          
Viewpoint
標準の視点の後ろに、ファイル内のカメラが並びます。焦点距離のアニメーションとエイム拘束も再現されます。

          
fps
秒とフレームの換算値で、ファイルから自動検出されます。フレーム番号、コマ送りの幅、Snapの丸め先、Rangeの境界を決めます。再生速度は変わりません。

          
Range
区間を指定して再生します。オフにしてもStart/Endの値は保持されます。

          
Snap
実時間ではなく整数フレームでポーズを拾います。DCCのタイムラインと同じ送り方になります。

          
Skeleton Ghost
前後のフレームのスケルトンを重ねて描画します。範囲・間隔・方向はGHOST枠で調整します。

          
Gate Mask
FBXカメラのレゾリューションゲートです。Gate Fitをファイルから読むので、元のDCCと同じ構図になります。

          
Units
グリッドは1セルが1メートルです。ファイルが記録している単位スケールから換算するので、センチメートルで作られたシーンでも1セルは1メートルになります。Grid Sizeを1つ上げるごとに一辺が10セル増えるので、レベル1は10メートル四方です。

          
Grid Fill
グリッドを塗りつぶす面です。片面なので、上から見れば地面下が隠れ、下に回り込めばそのまま見えます。

          
Frame Cameras
Frameの対象範囲にカメラと注視点を含めます。

          
Visibility
メッシュごとにShow/Hide/Animを巡回します。Animはファイルの可視性キーに従い、グループが非表示なら配下のメッシュも非表示になります。可視性はキー位置でオン/オフが切り替わる扱いで、3ds Maxのようなリニアな半透明化には対応していません。

          
Hidden in 3ds Max
3ds Maxはオブジェクトの表示/非表示をVisibilityトラックとは別に持っており、書き出しでも別の情報になります。どちらも読み込みます。表示/非表示が効くのはそのオブジェクト単体で、ボーンやダミーを隠しても配下は残ります（Maxと同じ挙動です）。両方を持つメッシュではVisibilityトラックが優先されるので、カット中に切り替えたいものはVisibilityにキーを打ってください。
